# What's New in .NET 10

.NET 10 introduces a wide range of new features and improvements across the runtime, libraries, SDK, and ASP.NET Core. This document highlights the key new features and enhancements.

## Runtime Enhancements

- **Improved JIT Compilation** - Enhanced Just-In-Time compilation with better method inlining, devirtualization, and stack allocation optimizations for improved performance
  - [What's new in .NET 10 Runtime](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/runtime)

- **AVX10.2 Support** - New support for AVX10.2 instruction set, which enhances performance for applications that use heavy numeric computations
  - [What's new in .NET 10 Overview](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/overview)

- **Performance Improvements** - Significant performance gains through various runtime optimizations
  - [.NET 10 Performance Improvements](https://devblogs.microsoft.com/dotnet/performance-improvements-in-net-10/)

## Library Updates

- **New APIs** - Expanded APIs in cryptography, numerics, globalization, and JSON serialization
  - [What's new in .NET 10 Libraries](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/libraries)

- **Post-Quantum Cryptography** - Enhanced support for post-quantum cryptography algorithms to prepare for quantum computing threats
  - [What's new in .NET 10 Overview](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/overview)

- **WebSocketStream** - Improved WebSocket handling with the new WebSocketStream API for better streaming scenarios
  - [What's new in .NET 10 Libraries](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/libraries)

## SDK Improvements

- **Enhanced CLI Tools** - Native tab-completion support and CLI command standardization for better developer experience
  - [What's new in .NET 10 SDK](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/sdk)

- **Container Image Generation** - Easier generation of container images for console applications directly from the SDK
  - [.NET Container Images](https://learn.microsoft.com/en-us/dotnet/core/docker/container-images)

- **Improved Developer Experience** - Various improvements to make development faster and more intuitive
  - [What's new in .NET 10 SDK](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-10/sdk)

## ASP.NET Core

- **Blazor WebAssembly Preloading** - New preloading capabilities for Blazor WebAssembly applications to improve startup performance
  - [What's new in ASP.NET Core 10.0](https://learn.microsoft.com/en-us/aspnet/core/release-notes/aspnetcore-10.0)

- **Form Validation Enhancements** - Improved form validation features for better user experience
  - [What's new in ASP.NET Core 10.0](https://learn.microsoft.com/en-us/aspnet/core/release-notes/aspnetcore-10.0)

- **OpenAPI Support** - Enhanced OpenAPI support with better integration and tooling
  - [OpenAPI in ASP.NET Core](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/openapi)

## C# 14

- **New Language Features** - C# 14 introduces new language features aimed at improving developer productivity and code quality
  - [What's new in C# 14](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-14)

- **Enhanced Pattern Matching** - Additional pattern matching capabilities for more expressive code
  - [C# Pattern Matching](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/functional/pattern-matching)

.NET 10 brings substantial improvements across all areas of the platform, with a strong focus on performance, security, and developer productivity. These enhancements make .NET 10 an excellent choice for building modern, high-performance applications.
